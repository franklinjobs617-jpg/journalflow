# 2026-06-09

## 修复 Next.js build 报错

**问题**：`app/page.tsx`（Server Component）第 259 行有一个 `<a onClick={...}>` 事件处理函数，违反 RSC 规则——Server Component 不能传 event handler 给 Client Component props。

**根因**：`Event handlers cannot be passed to Client Component props`，打包时 static page generation 超时并报错。

**修复**：将该 `<a onClick>` 替换为 `<Link href="/#generator">`，并在 Generator 组件外层加 `<div id="generator">` 锚点。

**结果**：build 成功，36 个静态页面全部生成，Exit Code 0。
